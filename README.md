## 3. Hướng dẫn gia nhập

1.  Liên hệ một trong các ban qua email trong bảng để nhận thông tin đăng ký.
    
2.  Cài đặt [Git](https://git-scm.com/) và [Visual Studio Code](https://code.visualstudio.com/).
    
3.  Tạo tài khoản [GitHub](https://github.com/) và cấu hình tên, email Git trên máy:
    
    ```
    git config --global user.name "Ten Cua Ban"
    git config --global user.email "email@example.com"
    ```
    
4.  Sau khi được cấp quyền truy cập repository của CLB, sao chép dự án về máy (thay URL mẫu bằng URL repository thực tế):
    
    ```
    git clone https://github.com/OWNER/REPOSITORY.git
    cd REPOSITORY
    ```
    
5.  Đọc `README.md`, làm quen với quy trình làm việc và liên hệ Ban Kỹ thuật để nhận nhiệm vụ đầu tiên.
    

## 4. Checklist nhiệm vụ thành viên mới

-   Đọc tài liệu giới thiệu CLB.
-   Xem danh sách các ban và kênh liên hệ.
-   Hoàn thành đăng ký gia nhập.
-   Cài đặt Git và VS Code.
-   Tạo tài khoản GitHub.
-   Clone repository được cấp quyền.
-   Hoàn thành nhiệm vụ đầu tiên.

## 5. Lưu ý quan trọng

> **Deadline:** Hoàn thành các bước gia nhập trong vòng **7 ngày kể từ khi nhận thông báo chấp nhận** (mốc minh họa, cần CLB xác nhận).
> 
> **Quy tắc ứng xử:** Tôn trọng thành viên khác; trao đổi lịch sự, không công kích cá nhân; ghi rõ nguồn khi sử dụng tài liệu hoặc mã nguồn của người khác; không công khai mật khẩu, token hay thông tin cá nhân lên GitHub.
> 
> Khi gặp lỗi hoặc liên kết không hoạt động, hãy liên hệ Ban Kỹ thuật để được hỗ trợ.
